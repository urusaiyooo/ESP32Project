# v1.4.6 视频版验证

- S3 固件编译通过：静态 RAM 52,140 字节，应用 4,848,625 字节，应用分区仍为 6.25 MiB。
- 23 项自动化测试通过：14 项额度/分区/镜像/视频校验测试，9 项 USB 协议/账号窗口/任务状态及积分汇总测试。覆盖视频损坏、索引越界、错误芯片、篡改分区表及异常地址拒绝。
- 自包含 DeskHubFlash.exe 对五个镜像的 SHA256、S3 标记、视频 CRC/索引和固定分区表校验通过。
- 已在实际 ESP32-S3 N16R8 上备份配置区并写入新分区、应用和完整视频，写入哈希验证通过；NVS 未擦除，原触摸校准 calibrated=1 保留。
- 第一轮实测放大到 480×270 时平均渲染约 131ms；最终改为原生 320×180 居中显示。
- 最终固件实测完整播放 110,000ms：1320 帧全部显示，跳帧 0，平均渲染 73.38ms，达到 12 fps。运行结果不是任意素材/负载下的帧率保证。
- 验证左侧人物点击启动、播放时点击退出、完整播放结束自动恢复时钟、中央透明菜单入口、音乐菜单及返回均通过。
- 视频读取、JPEG 解码和绘制在 S3 完成，测试时电脑采集后台暂停，仅用串口读取诊断与注入触摸手势；没有电脑视频流。
- 播放结束释放视频缓存后恢复时钟；剩余 PSRAM 8,264,519 字节。

电脑后台沿用已验收的 Windows 1.4.4 版本。当前硬件不提供声音。画面观感及实体触摸仍需用户现场确认；未在另一台全新电脑重新安装。
